## 宿題

- 取り組んだレベル：発展
- やったこと：SWE-bench Verified の公開データセットから Astropy の3件を選び、問題文、修正が求められる挙動、難しさを比較した。作成・検証手順は OpenAI の公開記事と元の SWE-bench 論文を参照した。[データセット](https://huggingface.co/datasets/princeton-nlp/SWE-bench_Verified/viewer/default/test)

### 問題の内容と難しさ

1. **`astropy__astropy-12907`**：複合モデルを入れ子にすると、互いに独立した出力まで同じ入力に依存すると判定される。再現例があるので調査は始めやすい。LLM が修正するには、モデルを結合するときに子モデルの依存行列をどう配置するかを追い、別の入れ子や演算でも期待どおりかを確かめる必要がある。[問題文](https://github.com/astropy/astropy/issues/12906)
   - 自分なら、B と C を先にまとめた場合とそのまま並べた場合で、B は入力①だけ、C は入力②だけを使うと判定されるかを比べる。
2. **`astropy__astropy-13033`**：時系列テーブルの必須列が足りないときに、実際の状態が分かりにくい例外メッセージが出る。3件の中では、必須列の検査処理から修正箇所を絞りやすい。LLM が修正する場合も、例外が出る箇所を見つけ、列が一部あるケースと空のケースで状況が伝わるかを確認する必要がある。[問題文](https://github.com/astropy/astropy/issues/13009)
   - 自分なら、必須の `time` 列と `flux` 列のうち `flux` 列を削除し、両方の列が必要だと分かるメッセージが出るかを確かめる。
3. **`astropy__astropy-13236`**：構造化 NumPy 配列をテーブルに追加する際、既定で `NdarrayMixin` に変換される挙動を見直し、`Column` として扱う。LLM が修正するには、既定の変換経路を特定し、欠損値を示すマスクの保持など、変換後の挙動まで確認する必要がある。データ型と互換性の調査から始める課題だと考えた。[問題文](https://github.com/astropy/astropy/issues/13235)
   - 自分なら、温度は測定済みで湿度は未測定のデータを表に追加し、通常の列に変換された後も湿度が欠損値として扱われるかを確かめる。

### 結果

- **作成・検証**：元の SWE-bench は、論文著者7人が公開 Python リポジトリ12件の実際の issue と修正 PR から構成した。Verified では、Python 経験のある開発者93人が、抽出された1,699件を1件につき別々の3人で検証した。問題文の情報不足、妥当な修正まで落とすテスト、その他の重大な問題を調べ、最も厳しい判定に従って約68.3%を品質上の理由で除外した。残りから難度を考慮して500件を採用した。[元の論文](https://arxiv.org/abs/2310.06770)・[Verified の公式記事](https://openai.com/index/introducing-swe-bench-verified/)
- **講義の評価セットとの違い**：講義では、講師1人が用意した質問と回答10件に、人と LLM が根拠・範囲・ヒント・分かりやすさのラベルを付け、一致率や要確認の件数を測る。「第N回」の末尾表示はコードで確認する。Verified では、開発者は問題とテストの品質を事前検証し、モデルのパッチはコードで採点する。採点時は、修正で通るべきテスト（`FAIL_TO_PASS`）と、引き続き通るべきテスト（`PASS_TO_PASS`）の両方を実行する。[第4回の演習手順](https://github.com/matsuolab/lecture-ai-engineering-2026/blob/lec04-start/lectures/04/problem.md)・[Verified の公式記事](https://openai.com/index/introducing-swe-bench-verified/)

### 気づき・疑問

テストで自動採点する場合でも、事前に人が「問題文から要求を読み取れるか」「別の妥当な修正が落ちないか」を確かめている。講座の評価でも、末尾の「第N回」は文字列で確認できるが、根拠に沿っているかを測るには、判定に必要な参照と具体的な基準が要る。たとえば、回の表示があることに加えて、表示された回が内容と対応していることまで測るには、どんな参照情報を渡せばよいかが気になった。
